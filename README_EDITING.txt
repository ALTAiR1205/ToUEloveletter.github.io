使用说明（v7.3 起，新增内容超简单）：

1. 所有信件、回信、碎碎念、歌单都在 content.js 里改，其他文件不用动。

2. 新增一封信 / 一条碎碎念 / 一封回信：
   只需要在对应数组里加一个对象，放在【任何位置】都行（建议放最上面方便找），
   而且【不用写 id，不用写 kicker，不用管顺序】——页面会按日期自动排序（新的在前）、
   自动生成 id 和编号。最少只要这几行：

   {
     date: "2026.07.07",
     meta: "2026.07.07 / 晚上 / 在家",      // 可选
     title: "标题写这里",
     tags: ["想你", "我爱你"],               // 可选
     body: `<p>正文写这里，换行用 <br/><br/></p>`,
   },

3. 修改旧内容：直接改文字即可，但【不要改旧条目的 id】，不然她收藏过的链接会失效。

4. 歌单在 content.js 顶部 playlist 里改，音频文件放 music/ 文件夹。

5. 改完 content.js 直接 commit + push 到 main，网站一两分钟后自动更新。

6. 三个主题模式（夜晚/白天/花开）的背景视频都在 media/ 文件夹，
   同名替换文件即可换素材（换完最好把 index.html 里 ?v=x.x 版本号改一下强制刷新缓存）。

7. （v10）定时信：给信件加一行 unlockAt，到点之前它不会出现在任何页面，到点自动出现。时间一定要带时区：
     unlockAt: "2026-11-04T00:00:00+08:00",    // 北京时间 11 月 4 日零点
   提前写好、提前上线都没关系。

8. （v10）生日章：content.js 顶部的 birthday 里改文案、时间和愿望清单。
   - 二十一个愿望里哪一条实现了，就把那一条的 done 填上日期，网页上会点亮并显示“已兑现 · 日期”：
       { t: "陪你坐人生第一次摩天轮，在最高的地方亲你一下。", done: "2026.12.20" },
   - 上线前想自己预览：在网址后面加
       ?bday=teaser   零点前（封着的信 + 倒计时）
       ?bday=t-10     零点前 10 秒（看零点现场拆封）
       ?bday=party    生日当天（开屏、首页封面、吹蜡烛、拆信）
       ?bday=after    生日过后（这一章挪到「宇宙边缘」前面永久保留）
     预览只影响生日这一章（章里能拆信看全文）；信件列表和档案里，生日信照样要等到点才出现。

9. （v10）主模式是白天。按钮循环：白天 → 夜晚 → 花开 → 草原。
