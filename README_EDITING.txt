使用说明：

1. 以后新增或修改信件、回信、碎碎念、歌单，只改 content.js。
2. index.html 是主页缩略图展示；archive.html 是全部档案；article.html 是统一阅读页。
3. 不再需要 letters/、replies/、fragments/ 这些文章子目录。GitHub 仓库里旧的这三个文件夹可以删除，也可以留着，但新版不会再使用它们。
4. music/ 文件夹继续保留，歌名和路径在 content.js 的 playlist 里改。
5. 上传时把本包里的 index.html / archive.html / article.html / style.css / script.js / content.js 一起放到仓库根目录。
